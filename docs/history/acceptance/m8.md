## Backup, restore, retention, and recovery

The retained pre-upgrade backup is
`/var/backups/agent-workspace/m8-final-preupgrade-d44652b8a`. Its PostgreSQL
18 custom dump, data archive, release archive, and manifest passed checksum
validation. The ordinary backup excludes every credential/session class.

A clean-location restore created a new database and new owner-only data and
release roots, started the backed-up artifact on alternate loopback ports,
and reconciled without editing the database. It restored no browser session,
password, MCP/OAuth credential, OAuth grant, or authenticated provider cache.
All 17 retained worktrees were inspectable: ten dirty and seven clean. The
drill database, roots, environment, and transient unit were removed after the
proof; the validated backup remains.

Operational retention deleted 37 expired idempotency rows and three expired
OAuth authorization-code rows. These 40 operational rows were permanently
removed; no Message, Work Item, Actor attribution, audit history, run,
provider identity, or repository work was deleted. A repeated dry run returned
zero candidates. Retained-worktree cleanup returned zero candidates and
preserved every dirty, unpushed, non-terminal, or ambiguous tree.

The storage report measured PostgreSQL and every registered runtime root
without following 12 symlinks. A deployment-discovered admission mismatch was
fixed in PR
[#78](https://github.com/Mischa-dev/agent-workspace/pull/78): runtime accounting
now skips symlink entries exactly like the report while the independently
validated runtime roots and provider sandbox stay unchanged. The accepted host
reported about 124.5 GB free and admitted growth.

## Cleanup and residual boundaries

Credential-free transfer bundles and clean restore-drill resources were
removed. Clean obsolete M7/M8 temporary worktrees were removed through Git;
their commits remain recoverable. The retained backup and dirty acceptance
worktrees are intentional evidence and were not reset or deleted.

The private beta remains a loopback/SSH-forwarded single-host deployment. It
does not claim public multi-tenant isolation, an uptime SLA, automatic
off-host backups, attachment support, or external-agent support. Those are
separate decisions and milestones.

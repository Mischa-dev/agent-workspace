## Accepted boundary

M7 adds owner-issued single-use Project invitations, local account creation,
human membership lifecycle, an exhaustive role-to-action policy, useful viewer
restrictions, Actor-specific Thread attention, and invoker-owned personal Codex
Execution Profiles. It does not add public signup, email delivery, custom
roles, shared provider credentials, OIDC, passkeys, service profiles, or
external agent members.

Every human action continues to resolve authorship from the authenticated
server session. Project managers may see only safe Execution Profile readiness;
provider identity, credentials, limits, history, and raw failures remain
visible only to the profile owner. A hosted run may select only an active,
authenticated, same-Project profile owned by its requesting Actor.
